These are new source-row projections, not original stored event evidence or proof of database identity/snapshot authenticity. Fingerprints are unkeyed metadata and can coincide across equal database snapshots; they are not generation IDs or authorization tokens. No wildcard row serialization can automatically leak a future added column.

The context observedAt is that statement's observation time, not a guarantee that repeated context calls return an identical timestamp. A later full export collector must preserve its first context and own a distinct generation ID. These routines alone do not impose a whole-job deadline, aggregate memory/row budget or business-wide lease; the later owned collector/worker must supply those under the canonical export protocol.
