## Decision and authority

Schema18 adds a fixed SECURITY DEFINER provider_session_inventory(actor,issuer,after_session,page_size) routine, owned by the new nonlogin/noninheriting crest_inventory_owner. A separate nonlogin crest_inventory caller gets only schema resolution and this execution grant. No login, password, membership, scheduler, runtime adapter, HTTP route or production configuration is provisioned. Ordinary web, worker, recovery, provider browser/service and existing session-reader/issuer roles cannot call or assume it. Later maintenance provisioning must use a separately reviewed login/connection; never add this membership to an ordinary application credential. The generic worker is not maintenance authority.

The restricted definer receives only SELECT of the same four provider session columns already reviewed by schema4 (id,user_id,not_after,aal), six actor-binding fields, six local session identity/lifetime fields and four token-free cleanup-reference fields. ## Observation contract

The caller supplies the configured exact issuer and durable owner actor ID, not an arbitrary provider subject. The function resolves that existing binding to its canonical UUID subject, rejects unknown/system/non-UUID bindings and issuer mismatch, and filters auth.sessions by that exact subject. Disabled actors remain inspectable for maintenance. The output contains only provider session UUID, optional same-actor local session and cleanup-reference UUIDs, provider AAL/deadline/unexpired flag, local revocation/expiry, current-epoch comparison, actor-disabled flag and database statement observation time. It does not return contact information, issuer secrets or reusable authority. An unregistered row has NULL local fields. An unexpired AAL2 provider row is not a claim of application eligibility: membership, idle deadline, credentials, current SDK verification and request authorization are still required.

Calls require READ COMMITTED, allow read-only transactions, pin search_path/row_security and use a STABLE calling-statement snapshot for both binding and projection. Each call returns at most100 rows (page_size must be1..100; an empty result is valid), ordered by provider UUID with an exclusive optional last-session cursor. There is no offset or arbitrary query. This does not prove a constant query cost or authorize running without connection/statement limits: a future adapter must enforce bounded connection/statement time, page count, total rows and run duration. No provider-owned indexes are changed. Full-size capacity measurement remains open.

Each page is an observation, not a durable finding, lease, revocation authorization or cross-page consistent snapshot. Concurrent inserts below a cursor can be missed until a fresh sweep. Concurrent login/registration/revocation/provider deletion can change the next observation. Empty/complete pagination proves neither provider absence nor cleanup success. This function does not enumerate provider users without an existing Crest actor, locally retained sessions whose provider row is already absent, or old provider environments. Those remain explicit downstream reconciliation cases. No row is marked orphan, even with an old timestamp: an in-flight or uncertain login cannot safely be deleted from this evidence alone.
