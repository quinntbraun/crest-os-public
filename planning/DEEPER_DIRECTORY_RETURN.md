# Address, service, source and lead directory return

The shared in-memory DirectoryOrigin behavior now covers addresses, services, lead sources and lead intake/follow-ups, alongside customers and vehicles. Opening a record captures its actual entry control, page position, viewport dimensions and any scrolling ancestors. Back restores that context; a changed viewport uses a visible focused control instead of an obsolete pixel position. Address/service Back controls are also available on desktop.

Address, service and lead Back actions retain unfinished drafts and their existing explicit resume controls. Source Back still asks before discarding a dirty source; cancelling keeps the editor, accepting returns to the unchanged saved row. Cancelled searches and pagination keep the original draft/context. Lead pagination now uses the same discard decision as search instead of silently replacing dirty intake. Accepted queries, filters and pages clear stale origins. Private clearing, pagehide, bfcache restoration and disposal clear references; context is never put in URLs or browser storage. Existing pending-save formats and business commands remain unchanged.
