Constructor configuration pins the business and database; no environment lookup, caller SQL, pool/sink callback, browser credential or runtime route. It uses the existing separate crest_export principal, never provider inventory/web privileges. Retain exact original UTF8 source JSON text, decimal-string versions, UTC microseconds and hashes. Check exact envelope/shape/scope/counts, forward cursor, body hashes, UTF8, per-source and aggregate bounds.
