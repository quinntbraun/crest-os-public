Version: 1.4 | 2026-10-20 | Canonical V1 baseline adopted for implementation; production activation gated


Public edition, 2026-10-20: owner-authorized public source; application access and business evidence remain private. PUBLICATION.md records this explicit privacy/provenance amendment and the current authority/version register. Earlier private-repository and budget/authorization statements below are historical where superseded there. No security, accounting, recovery or real-data activation gate is waived.

Every slice uses the common definition of complete in TESTING.md, includes its export representation and follows versioned SQL migrations. No real customer data during construction. Keep slices reviewable; each phase may consist of several small PRs. Do not postpone recovery to the end.

Dependency safety: accepted scope allocation must be designed before invoices; financial semantics before finance implementation; auth/file/backup boundaries before real evidence; import matching before full cutover. Exports are built per domain then integrated, not retrofitted after schema grows. Recovery is established in phase3 and repeatedly expanded. PWA refinements run throughout field slices; phase13 proves complete usability rather than introduces it for the first time.

Rollback does not mean automatic reverse migrations. Old deployment is permitted only within schema compatibility range; otherwise pause writes and forward-fix or execute explicit restore/reconciliation. No infrastructure purchase/deployment or customer messaging is authorized by this roadmap itself.
