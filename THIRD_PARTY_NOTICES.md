# Third-party components

Crest OS is private business software. Its own source is not relicensed by this inventory. Exact dependency versions, license identifiers and archive integrity hashes are in package-lock.json. `npm run verify:dependencies` rejects unreviewed license identifiers or non-registry dependencies. The inventory includes optional platform packages that are not installed on every host.

Direct runtime components Next.js, React and React DOM use MIT licenses. TypeScript, Playwright and ESLint JavaScript configuration use Apache-2.0/MIT as recorded in the lockfile; pg, Vitest, ESLint and TypeScript ESLint use MIT. The axe Playwright adapter and axe-core use MPL-2.0: retain their license notices and make any modified covered files available under that license when distributing. No covered dependency source is modified here.

Next.js includes sharp (Apache-2.0) and platform image binaries with libvips (LGPL-3.0-or-later). Preserve their bundled notices and license files. For any distribution outside Crest, supply the corresponding native-library source/build materials and relinking/replacement rights required by those licenses; do not assume a JavaScript MIT notice covers native libraries. Upstream packaging/source: https://github.com/lovell/sharp-libvips and https://github.com/libvips/libvips. Platform archive package versions are pinned in package-lock.json; native license details: https://sharp.pixelplumbing.com/install/#licensing. Production release preparation must retain the matching notices and source materials with the release/recovery package. No external binary distribution or production release is performed in Phase 1.

Supabase CLI is MIT; PostgreSQL uses the PostgreSQL License; pgTAP uses the PostgreSQL License; Gitleaks is MIT. k6 is AGPL-3.0, runs only as a separate testing tool in later measured workload stages, and is not linked into or shipped with the application. Debian/Node base-image licenses remain in their packages and `/usr/share/doc`; preserve them with any distributed image. The complete release inventory includes OS packages, native-library components and tooling, not only npm packages.
